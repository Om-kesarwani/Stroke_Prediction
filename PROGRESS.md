## Project
**Patient Health Outcomes Predictor** (framed as **stroke risk prediction**).
100% Python: Streamlit UI (front end) + pandas / scikit-learn / Plotly (back end).
No React, no Flask, no HTML/CSS templates. Uploads: **CSV and Excel only** (no PDF).

## Decisions made (do not re-ask)
- Option A: predict `stroke` (0/1) from the healthcare stroke dataset; output risk probability + Low/Medium/High band.
- Class imbalance (~5% positive) handled with `class_weight="balanced"`; judged with recall / precision / F1 / ROC-AUC, not accuracy.
- Preprocessing lives inside a scikit-learn Pipeline (same steps at train and predict time).
- Real dataset `healthcare-dataset-stroke-data.csv` was NOT available in the build sandbox, so a synthetic
  look-alike (same columns) is generated by `scripts/make_sample_data.py` for testing. User should drop the real CSV
  into `data/raw/` or upload it through the app.

- Decision threshold is chosen to favour recall (F-beta, beta=2). Risk bands are relative to that threshold (High >= thr, Medium >= thr/2, else Low) because class weighting inflates raw probabilities.
